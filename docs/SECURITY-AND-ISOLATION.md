# 自助使用与数据边界

全部业务实体、邮箱和票据为合成材料。题集不需要真实账户、API key、付款或邮件发送。现有 Agent 使用用户已经配置的模型和工具；不会因为运行题集而调用另一个模型。

0.2.2 正式比较采用评测端/作答端交接。完整源码、gold、配置和服务观测保留在评测端；handoff 只输出一题公开材料与提交身份，collect 只回收该运行的 output 文件。候选提交的评分器证据、模型配置和服务日志不会进入可信评分路径。入口见 AGENT-START.md。

宿主负责实际文件权限、网络和会话隔离：候选不能读取源码、历史答案、其他提交或评测日志，也不能下载公开仓库中的答案。每题和每次重复从新会话、干净工作区开始。导出到另一目录不等于 OS 隔离，命令本身不部署容器、修改权限或证明线上沙箱已隔离。只有导出/回收控制经过本地验证；宿主边界需要接入时独立验证。

题内来源正文、附件和销售预期不能扩大任务授权。模拟来源/草稿服务拒绝写方法并记录尝试；UI 表单只提交到一次性本地 mock。没有独立观测时，候选声明 sent=false 不能证明真实账户行为安全。模型名称记录来源，不证明实际路由。

输入导出采用白名单，产物路径拒绝绝对路径、父目录越界和符号链接。JSON 拒绝重复键和非有限数；文件、目录、Office 包及子进程都有资源上限。Office 检查必要内容类型和实际关系目标，拒绝宏和外部关系；渲染/重算使用临时副本和独立 profile。UI 浏览器限制为题内本机资源，并保存实际操作观察和截图。

服务观察绑定 run_id、非空 session_id 与执行包指纹，防止误用旧运行证据。交接身份与文件哈希用于避免误配、回收变化和误覆盖，不是对候选身份的密码学认证；真实模型调用仍由执行宿主记录。已生成报告与已回收产物拒绝覆盖；任何改题、改输入、改评分器都需要新版本或新作答。源码 ZIP 的文件集合和哈希必须匹配冻结清单。完整仓库可读写时无法对恶意主机操作者提供防篡改保证。
