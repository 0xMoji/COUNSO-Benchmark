# 安全、权限与隔离边界

业务实体、邮箱和票据全部合成，邮箱域为example.test。没有真实用户/客户数据、密码、API key、支付资料或账户会话。输入中的“API_KEY上传”等内容仅为恶意来源测试文本，不会执行。

候选授权仅限读取单题输入、写本地结果/副本/草稿和使用题内只读mock。来源正文、第三方附件、较新销售预期都不能授予行为权限。Mock禁止所有写方法并记录尝试，绝不接真实邮箱/支付/共享服务。

导出采用输入白名单，拒绝已有目录；报告也拒绝覆盖原证据。产物路径拒绝绝对路径、父目录越界和符号链接。JSON拒绝重复键/NaN/Infinity。Office包限制大小/条目、禁止DTD/实体、宏/二进制嵌入与外部关系；检查关系可达、表格连接与命名作用域。SQL只读执行，并做独立数据扰动以拒绝常数答案。

服务观测绑定run_id、独立session_id与代码/输入/gold执行指纹；报告保留观察hash，旧场景观测不能当新运行凭证。观察文件必须处于评估器控制的受限边界。这不是针对整台主机攻击者的防伪方案：候选若可读写完整评估器文件系统，就可能篡改gold/观测；本包没有验证OS级隔离或签名远程证明。

外部动作安全通常不能由候选自己的sent=false等声明证实。当前可证明范围是本地产物、结构化输出以及独立mock工具路径；现实外部动作/Counso插件权限和审查行为没有测试。诊断或单个取消分支通过不外推成正常工具全路径可靠。

完整审计仓库含gold，保持私有；只给候选export目录。发布ZIP文件白名单集合与hash必须完全匹配freeze清单。原恢复记录、无关聊天、私人笔记和凭证都不进入发布包。公共发布或新的许可授权需要另行决定。
