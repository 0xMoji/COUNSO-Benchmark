## Trusted host API

`startProxy({packageDir,kind,files,interfacePath,artifactDir,port:0})` returns `url`, `origin`, `sessionId`, `session`, `build`, `allowedPaths`, `routeAllowlist`, and `close()`. `url` contains a per-session runner-only token and must not enter candidate context. Only the six returned exact routes may be allowed by Playwright. No repository, environment or evaluator directory is statically served. Iframe selector: `#frame`.

Outer `window.frameProxy` exposes `control(action)`, `snapshot()`, `events()`, `reload()`. Candidates are in an opaque `allow-scripts allow-downloads` sandbox without `allow-same-origin`; CSP blocks external resources/connects/nested frames/workers/forms. Parent and iframe check exact source and identifier. Browser route denial is an additional required layer.

Controls: `replaceFiles` (same-schema JSON objects/text), `setReadOnly`, `setFileCapability`, `setFault`, `release`, `clearFaults`. Fault command is `getFile`, `writeFile` or `callFunction`; effect is `delay`, `hold`, `read_fail`, `function_fail`, `read_only`, `conflict` or `save_failed`. Delays/holds default after processing; refusal faults default before processing. Select an explicit phase for an exact preregistered schedule. `release` takes an actual `pendingId` and optional `outcome`: `function_fail` for a function, `read_fail` for a read, or `save_failed` for a write. A failure after a write commit does not roll back or erase the actual commit.

File writes are opaque strings, as in the verified SDK; the host never protects a candidate's wrong draft with a hidden business-rule validator. Only existing declared draft paths are writable. Positive revision, capability, package-root and conflict checks apply. Functions are only registered trusted `load-data`, returning deterministic fixture-derived data; candidate function source is not read or run, and no model/backend service is called.

`events.jsonl` records original requests/results, concrete fault matches, controls, actual commits and UTC/monotonic/hash-chain observations. `persisted-draft.json`, browser downloads, raw DOM, screenshots, build and package bindings and receipts are evidence. A Saved label, screenshot or successful compilation alone is not a functional PASS.
