# 通用办公整体能力信号摘要

主目标是先比较模型的通用办公整体质量，再看业务领域适配。速度独立报告，成本不进入能力排序。

目前四类强支架任务的主要业务结果近乎全对，可以支持有限合格性判断，不能据旧评分差异排通用办公整体实力。0–4分不必为了区分而硬拆小数；需要代表性覆盖、真实缺陷、交付可用性和独立重复。

40次确有粗计时，边界为编排提交附近到评估器收件，混有候选工作、排队、工具、并发和收件等待；随后评分和盲审不在跨度内。基线32次53.88–437.10秒，中位123.43秒；澄清8次110.53–256.03秒，中位178.86秒。仅作运行尺度说明，不按模型排名，也不比较不同契约的前后速度。B01服务观测只有顺序，桥接每事件仅一个时间戳，不能拆出工具耗时。

下一轮应先固定通用办公任务覆盖：证据检索整合、数据分析、文档/演示、约束编辑、多步执行、异常恢复。建议覆盖优先v1为8配置×6类×每类2个不同实例×1次=96次，可分两批48次；预先固定各类宏平均、类内任务等权，保留关键失败和UNKNOWN。另预留每类至少1个未见确认实例；重复资源用于对称补测临界或波动结果。它仍是小型基准，初始没有同题重复，不能外推所有办公任务。仪表不稳时可先仅做2配置×6例=12次测量校准；重复旧实例不能替代任务代表性。若只能跑32次，可做局部校准，但不能据两类任务命名完整通用办公排名。所有新实跑均仅为建议，未启动。

接受有证据的领先，也接受“目前不足以区分”的并列。业务切片第二层分析，速度和成本不用于打破能力平局。token、成本及实际后端快照当前未知。
