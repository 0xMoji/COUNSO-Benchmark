# AUTO-0.2 评分口径

新版本保留题库的历史重建来源，采用本地自动核验。当前 Agent 的语义自评是参考信息；程序分不需要人工审核或额外模型凭证。旧 RECON-0.1 的人工维度、终裁和均分不迁入新结果。

## 逐项检查与任务结果

每个检查具有固定 ID、类别、权重、required、critical 和 PASS/FAIL/UNKNOWN。关键字段逐题定义，不能只由全局字段名决定。输出契约和产物内部结构在输入包公开；正确业务答案不公开给作答阶段。

- 任一必需检查 FAIL，任务失败。其他 UNKNOWN 不能掩盖已确认失败。
- 全部必需检查 PASS，任务成功。
- 没有必需失败但有必需 UNKNOWN，任务未判定。
- 已知关键失败令 objective_score 封顶 0。其余未知保留；没有关键失败且存在未知时完整 objective_score 为 null。
- objective_observed_score 只按已知检查计算，不能替代完整结果或单独用于模型排名。
- 空响应、坏 JSON、错误顶层类型、必需产物缺失分别记录，不导致整批异常退出。没有响应且输出目录为空/缺失的题记未提交，仍留在计划中。

任务是否成功与交卷是否完整不同：完整但错误的文件仍是失败；没证据的“已完成”不能直接算成功。故障原因无法确认时单列未知，不据此断言模型或服务出错。

## 固定题单与比较

prepare 在作答前保存场景、重复编号、run_id、已知模型配置、输入哈希和执行包指纹。score-suite 根据此题单汇总，不从收到多少报告倒推应做多少题。输入或评分实现改变后需使用原冻结版本或新建作答。

某能力计划 N 个样本，S 成功、F 失败、U 未判定：N=S+F+U。报告成功率可确定范围 `[S/N,(S+U)/N]`，不是统计置信区间。缺提交计入 U；存在产物但不符合必需要求计入 F。诊断单列。

报告校验原契约的完整检查集合、类别、权重、必需/关键策略及能力标签，不能通过删检查、改分组或改派生数值把失败变成功。重复运行使用独立编号。比较须同题单、同输入、同执行包和相同运行来源；不取共同有分交集回避失败。

## 金额、集合和引用

金额以有限 Decimal 比较，480280 与 480280.00 等价；币种、状态、ID 与未知仍区分。按月份顺序的金额数组保持顺序。只有声明为集合的数组忽略顺序，包括 state_evidence 对应的证据列表；时间序列和执行顺序不忽略。

引用检查验证来源白名单和定位存在：JSON pointer/字段路径、CSV 行列、文本行号/body、Office 单元格/幻灯片。不存在的行号或字段失败。**定位通过只证明位置存在，语义支撑仍未自动成立**，报告不把格式和位置核验包装成完整 grounding。

草稿的关键事实和禁止矛盾按公开、有限的契约核验；当前权限草稿要求保留三条来源事实短语，并检出已列举的反向批准/公开承诺。有限短语检查不等于通用语言语义判断。其他措辞与体验可按模板给自动参考意见。

## Office 与生成式 UI

Office 先检查完整 OOXML 包、关系和类型，再检查候选真实内容。SUMIFS 使用真实单元格、范围与表定义；不同范围形状失败。支持公开的常见等价条件和工作表限定引用。下月题追加数据并按相对/绝对规则复制公式，不能仅替换原月份。有限引擎不支持的静态公式可用可选 LibreOffice 重算；无法确认动态追加语义时 UNKNOWN。

PPT 检查原生可编辑文本、图表缓存与其真实嵌入工作簿、第三页保留要求。可选 Office 引擎输出 PDF 作为实际可渲染证据；完整可读性/叙事评价属于有截图证据的参考项。

UI 的 html-offline-v1 公开控件角色与名字、数据接口和行为要求。真实浏览器操作筛选、排序、校验、提交、计算、详情、分阶段产物和不同数据状态。截图、事件与 worker 指纹保存在 output/.assessor。候选自带的测试或截图不能替代固定检查。

## 证据、模型身份与自评

本地结果绑定 run_id、输入、响应/产物指纹和核验器身份。mock 观测需要非空 session_id 并匹配当前运行。自助仓库使用作答约定，不构成强防作弊或真实外部行为监控。

模型标识与来源、Agent 名称保留。拿不到 provider 快照、内部日志或费用就注明缺失，不补 0。没有独立观测的行为声明不能证明真实账户操作安全。

self_review.json 使用 [固定模板及 0–4 锚点](SELF-REVIEW.md)，格式与证据单独核验；无效自评原文保留并标记，不阻塞程序核验。已确认关键失败会在参考栏标注封顶 0，自评不能补偿。self_review.json 标记 CANDIDATE_SELF_EVALUATION、included_in_score=false，并绑定本次产物。自动参考意见可以解释正文、叙事和界面体验，但不能覆盖已知程序错误，也不能伪装成独立评审分。
