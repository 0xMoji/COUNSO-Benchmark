# 0.2.2 单题交接验证

日期：2026-10-14。范围：固定现有 Agent 环境、只更换模型的内部比较流程；单题导出、产物回收及独立评分。业务题目、输入和金标均未修改，评分契约仍为 AUTO-0.2。

## 本地结果

- Windows / Python 3.14：183 项测试，170 通过、13 跳过、0 失败、0 错误。
- 13 项跳过为 7 项可选 Office/浏览器/第三方库控制和 6 项主机缺少创建符号链接权限的真实链接控制；没有把跳过计为通过。
- 新增 10 项交接测试，其中 9 通过、1 项真实链接控制因上述权限跳过。

验证包括：普通题从单题包到回收评分；只换模型时保留既有比较流程；错误运行/重复/输入身份被拒绝；原提交拒绝覆盖；空交卷与坏 JSON 仍分别保留 UNKNOWN/FAIL；候选模型配置与伪造服务日志不被导入；候选 .assessor 与超限文件被拒绝。

服务题用真实本机 HTTP mock 验证公开客户端查回草稿，服务观测保留在评测端，回收后评分通过。独立 UI 预览脚本从导出包读取更新数据并提供题面表单接口，目录越界请求被拒绝。所有这些运行都是合成控制，不是候选模型成绩。

## 验证边界

`handoff` 只输出本题公开输入，不包含 gold、评分器、其他提交或服务观测。`collect` 校验身份，只回收 output 文件。此次没有接入或修改线上 COUNSO 沙箱，未验证其文件权限、网络权限或模型路由。

正式运行须由宿主只挂载单题包，并确认源码、历史答案、其他作答及评测日志不可读；每题/每次重复使用新的会话。题内 mock 的本机端口需要从作答沙箱可达。导出到不同目录本身不是 OS 隔离。

已有 Linux/Windows CI 会运行新增回归；浏览器/Office 集成继续由 artifact-integration 作业核验。远端结果以对应提交的 GitHub Actions 状态为准。
