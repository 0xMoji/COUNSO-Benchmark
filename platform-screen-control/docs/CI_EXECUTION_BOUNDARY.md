## Fixed controls

- Push triggers only the exact new evaluation branch and bounded source/input paths. No main/default/release changes, PR triggers, `pull_request_target`, external reusable caller or untrusted workflow input.
- Job ceiling10 minutes; separate dependency/precheck/test limits leave time for diagnostic artifacts. Batch size is measured on references before candidate jobs are scheduled.
- `contents: read`; checkout `persist-credentials: false`; no business/account secrets, npm authentication, generated credentials or new paid configuration.
- Fixed Node24.16.0, pinned official action commits, exact evaluator package versions and official-registry lockfile. Browser binary/image/version/SHA are observed per job; reproducibility is bounded to those actual receipts.
- Trusted Node compiler/test code only. Candidate React/TSX is static input: no candidate npm scripts, function entrypoints, backend handlers, arbitrary dependency installation or other model calls execute.
- Candidate iframe is opaque, scripts/downloads only, without same-origin. Fixed CSP and actual-browser request interception block external network. Only declared synthetic file/function operations and six trusted host routes exist. No repository, hidden evaluator, process environment or credential files are served.
- E0 delivery uses its public noncritical5-point budget. All browser atoms require actual visible behavior and source/host comparison. Compilation, element presence, hidden attributes or screenshots alone do not certify them.
- Real interaction traces, initial/unseen fixture and package/bundle hashes, downloads, source/host ledgers, DOM, screenshots, test-plan/observer digests and UNKNOWN reasons are retained. Candidate JSON cannot register evaluator evidence.
- Mock safety gates require proved specifically forbidden executed actions. Expected midflight read-only/conflict/unconfirmed save paths may pass if handled correctly.
- CI/browser acceptance time never enters candidate model speed. Provider inference, tokens, backend snapshot, true effort and cost remain UNKNOWN unless independently supplied.

1. Minimum actual-click/data-change/negative-control probe, job≤10min.
2. Frozen selected6-topic/3cal contracts and actual positive UI references plus deterministic mutations, each job≤10min. Reference control run determines safe batch size; no complete browser-platform rebuild.
3. Six native calibration trials on3 fresh tasks×2fixed configs, including actual UI acceptance. Diagnose UNKNOWN or ceiling before final main freeze.
4.48 main native trials,6tasks×8configs, maximum2concurrent.16UI artifacts receive the same fixed source/interaction/unseen acceptance. Candidate task deadline900seconds. Every main cell is one observation; no independent model repeats or holdout claim.

The ten-minute ceiling is not measured runtime, price or a free quota guarantee. Stop if a new paid/account configuration or unapproved charge is required. Parent/publisher records actual runs, commits, artifacts and account feasibility. Reference/mutation/unseen replays add no candidate/model trials.
