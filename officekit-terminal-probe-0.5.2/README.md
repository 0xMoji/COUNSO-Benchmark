# Optional terminal-evidence instrumentation control

This small synthetic CI test exercises a healthy reference dashboard and its
real Refresh button, then deliberately waits for an observer event that the host
never emits. It checks that the failed wait preserves the last actual DOM, PNG,
action log and authoritative synthetic tool ledger before teardown. It awards
no task/model score and does not alter a candidate app or the six tasks.

The separate precise-path workflow uses the installed official Chrome and the
kit's original locked Playwright dependency. It does not rerun the UI task suite,
call a model API, use secrets or include previous run records in its source.
Generated evidence is private run output, not source committed to this project.

For normal agent use, follow
[the agent quickstart](../office-capability-kit-0.5/docs/AGENT_QUICKSTART.md):
1. Export one public task with `officekit prepare-agent`.
2. Start `officekit host-agent` for an office tool task in a shared public workspace.
3. Give that public package to an existing files/shell-capable agent; it uses the fixed helpers and submits files.
4. Run `officekit grade-agent` on the operator's original host receipt, or the separate actual browser command for a static UI package.

The platform supplies the model. No model key or custom controller is required.
Chat-only, missing-tool, unshared-workspace and blocked-browser environments are
unsupported/UNKNOWN, not model failures. Unresolved visible semantics remain
UNKNOWN for source-bound review. Standalone HTML is not native Counso, Frames
or A2UI; those runtime interfaces have not been verified by this control.
